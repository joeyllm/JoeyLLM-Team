## 📄 File naming

Inside each week folder:

| File | When |
|------|------|
| `report.md` | Every week — the weekly progress summary |
| `tutor-YYYY-MM-DD.md` | Team + tutor meeting |
| `client-YYYY-MM-DD.md` | Meeting with the client |
| `sync-YYYY-MM-DD.md` | Short ad-hoc meeting — only if one happened |

Rules:

- **Type first, then ISO date** — same meeting types group together, and dates sort chronologically.
- **Pad the week number** — `week-01`, not `week-1`, or `week-10` sorts before `week-2`.
- **No empty files.** If a sync didn't happen, don't create the file. A missing file means "no meeting"; an empty template means "someone forgot".
